# Target Job Description

**Role:** Lead Azure DevOps (Cloud Engineer)
**Via:** N-iX, for an unnamed client in connected safety systems

## Summary

Cloud Engineer role focused on design, implementation, and maintenance of Azure-based cloud infrastructure powering connected safety systems. Secure data ingestion from mobile and embedded devices, scalable storage for telemetry and crash data, reliable notification services for emergency contacts, integration with mobile/embedded/algorithm teams, support for ML model deployment for crash detection, and alignment with cybersecurity and data privacy standards.

## Responsibilities

- **Architecture & Design:** Scalable Azure cloud architecture for telemetry ingestion, user data management, and crash event processing.
- **API Development:** RESTful APIs for mobile apps and BLE-enabled devices.
- **Database Management:** Optimized database design/performance for telemetry and event workloads.
- **Notification Workflows:** SMS, email, push notifications triggered by crash events.
- **ML Support:** Deployment and versioning of ML models for crash detection.
- **Automation & DevOps:** CI/CD pipelines for cloud services and infrastructure using Azure DevOps.
- **Optimization:** Monitor and optimize cloud resource usage, costs, performance.
- **Compliance:** GDPR, ISO/IEC 27001 aligned infrastructure and workflows.

## Requirements

- 5+ years cloud engineering, Azure preferred.
- Cloud-native services, serverless, API development, data pipelines.
- Security and compliance: encryption, identity management, regulatory compliance.
- PowerShell, Python, Terraform, or Bicep.
- Azure Monitor, Application Insights, or Prometheus.
- Azure Functions, API Management, Event Grid, IoT Hub, Blob Storage, Cosmos DB, PostgreSQL.

## Nice to have

- IoT, wearables, BLE integration, telemetry.
- MLOps exposure.
- Azure Solutions Architect / Azure Security Engineer certifications.

## Interpretation notes

- "Lead" in the title + the responsibility list suggests a senior hands-on role with some architectural authority, not a pure people-management lead.
- Mentions of BLE, crash detection, and emergency contacts strongly suggest a connected personal safety product (wearable or in-vehicle SOS), not industrial/OEM automotive.
- Azure DevOps (the CI/CD product) is specifically named. Do not conflate with "DevOps on Azure." The pipeline work uses Azure Pipelines, not GitHub Actions.
- Event Grid is named; Event Hubs and Service Bus are not. Doesn't mean they're wrong — but if you introduce them, be ready to explain why over Event Grid.
